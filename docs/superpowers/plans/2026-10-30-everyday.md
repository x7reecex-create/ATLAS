# ATLAS Everyday Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make ATLAS immediately useful and legible to an ordinary first-time user.
**Architecture:** Retain the standalone application and existing persistence. Add small pure helpers for home selection and Library matching; use existing delegated actions.
**Tech Stack:** HTML, CSS, vanilla JavaScript, Node tests, Playwright in existing GitHub CI.
**Spec:** docs/superpowers/specs/2026-10-30-everyday-design.md

## Global Constraints

- Preserve existing records, themes, storage schema, auth and integrations.
- No new runtime dependencies, analytics, sample user data or paid services.
- Four main destinations and controls at least 44px tall.
- Verify a separate preview; do not merge draft PR #40 or publish production.

## Review Focus

- Future tasks must not become implied obligations for today.
- Failed saving must preserve input without duplicate tasks on retry.
- Existing names, preferences and records must survive reload.
- Empty/filtered Library must preserve an understandable escape route.
- Large text and narrow landscape must not hide controls or overflow.
